# Лабораторная работа № 1 — Velociraptor

Развёртывание серверно-агентного стенда, сбор артефактов, VQL-детекции и автоматизация установки клиентов.

## Стенд

- SERVER-VELO — Ubuntu, сервер Velociraptor
- UBUNTU-CLI — Ubuntu, Linux-клиент
- WINDOWS-CLIENT — Windows 11, Windows-клиент
- Oracle VirtualBox, лабораторная сеть

## Содержимое

- `vql/new_in_temp.yaml` — поиск новых исполняемых файлов в Windows Temp (CLIENT).
- `vql/persistence_delta.yaml` — отслеживание новых записей автозапуска (CLIENT_EVENT).
- `vql/outbound_anomaly.yaml` — поиск соединений к высоким TCP-портам (CLIENT).
- `results/*_results.json` — результаты трёх лабораторных VQL-проверок.
- `automation/install_linux.yml` — Ansible Playbook для Linux.
- `automation/install_velociraptor.ps1` — PowerShell-сценарий для Windows.

## Полученные результаты

1. `new-in-temp`: обнаружен тестовый файл `lab1_benign_test.exe`.
2. `persistence-delta`: обнаружена тестовая запись `Lab1_Persistence_Test2` со статусом `added`.
3. `outbound-anomaly`: обнаружено тестовое соединение на порт `54321`.

JSON-файлы содержат минимальные поля, необходимые для подтверждения этих результатов.

## Условия выполнения сценариев

- Linux Playbook запускается локально с повышенными привилегиями. При первичной установке ему нужны локальные файлы `automation/files/velociraptor_client` и `automation/files/client.config.yaml` (не включены из соображений безопасности).
- PowerShell-сценарию при первичной установке требуется `velociraptor_custom.msi` рядом с самим сценарием; файл также не включён.
- Повторные запуски при уже установленной службе проверяют её состояние. Вывод фактических запусков необходимо приложить отдельными логами.

## Безопасность и комплектность

Исходные клиентские/серверные конфигурации, закрытые ключи, учётные данные, дампы памяти и архивы forensic-доказательств не публикуются. Для требований отчётности отдельно необходимы *обезличенные копии настоящих конфигураций* и *текстовые логи выполнения* Ansible/PowerShell. Они отсутствовали в полученном архиве и **не заменяются заглушками**.
